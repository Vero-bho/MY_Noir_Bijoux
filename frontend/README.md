# Frontend Noir Bijoux

React 19, TypeScript, React Router и Tailwind CSS. Сайт включает главную страницу, каталог, карточку товара, страницу мастера, конструктор четырёх типов украшений, корзину, оформление заказа, историю, сохранённые сборки и настройки профиля.

## Запуск

```powershell
npm ci
npm run dev
```

Dev-сервер открывается на `http://localhost:5173`. В режиме разработки запросы `/api` проксируются к backend на порту 4000. Если API недоступен, каталог и конструктор используют локальные данные. Корзина, сборки и история заказов сохраняются в браузере.

## Страницы аккаунта

`/login`, `/register` и `/profile/settings` доступны визуально, но не выполняют авторизацию, регистрацию или изменение профиля. Backend-обработчики аккаунтов удалены.

## Команды

| Команда | Назначение |
|---|---|
| `npm run typecheck` | проверка TypeScript |
| `npm run build` | production-сборка |
| `npm start` | запуск production-сборки |
| `npm run check:files` | проверка структуры и ссылок на PNG |

Все изображения проекта — PNG. Изображения каталога демонстрационные и не выдаются за реальные фото товаров.
